# Nook

A small Windows 11 taskbar widget that shows weather, what's playing and your next calendar event, without covering your browser tabs.

![CI](https://github.com/Talha-Arif-ACS/nook-desktop-widget/actions/workflows/ci.yml/badge.svg)

> Work in progress. Built with C# (.NET 10) and WPF.
